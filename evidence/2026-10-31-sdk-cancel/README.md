# SDK 안내 취소 재시험 · 2026-10-31

Pleos 2.1 / NaviHelper 3.0.5에서 기존 AVD를 복제하고 마중의 저장 정보를 지운 시험 환경을 사용했다. 사용자의 원래 AVD와 공개 서버의 픽업은 변경하지 않았다. 시험 장소와 탑승자는 합성 자료다.

- `SdkCancellationTest`: 같은 에뮬레이터에서 두 번 실행, 두 번 모두 취소 콜백 1회 수신. 안내 중지 상태 확인까지 각각 302ms·204ms
- `RouteRecoveryTest`: 실제 SDK와 메모리 DB의 로컬 HTTP API 사용. 백그라운드 경로 변경, 취소 후 위치 숨김 12초 유지, 새 안내 후 공유 복구, SDK 재연결까지 통과(65.399초)
- 처음 전체 시험은 공유 안내 동의가 없는 초기 상태여서 위치 서비스 시작 단계에서 중단됐다. 합성 자료를 사용하는 시험 초기화에서 안내 동의를 명시한 뒤 재실행했다. 일반 앱의 동의 절차는 변경하지 않았다.

과거 이슈 #56의 30초 안내 유지 현상은 이번 환경에서는 재현되지 않았다. 이전 실행의 원인이나 SDK 제공 측 수정 여부를 확정하는 기록은 아니다. 원본 경유지 좌표 `(0, 0)` 이슈 #13과도 별개다.

실차의 시동 종료나 실제 휴대전화 알림 수신 시험을 포함하지 않는다. 시험용 SDK API와 결과는 opt-in이며 일반 CI에서는 에뮬레이터 실행을 요구하지 않는다.
