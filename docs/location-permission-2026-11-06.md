# 첫 픽업의 위치 권한과 공유 시작

첫 픽업이 시작됐는데 위치 권한을 허용하지 않으면 차량 위치·도착 시간이 전송되지 않았다. 이전 화면은 이를 ‘화면 밖에서도 공유 시작’ 버튼으로만 안내해 처음 사용하는 사람이 이유를 알기 어려웠다.

## 바뀐 흐름

1. 사용자가 위치 공유 안내에 동의하고 픽업을 시작한다.
2. 위치 권한이 없으면 화면에 이유를 표시한 뒤 Android 권한 창을 연다. 정차 중이고 앱이 앞에 있을 때만 요청한다.
3. 허용하면 별도 공유 시작 버튼 없이 공유 서비스를 시작한다. 이미 권한이 있으면 다시 묻지 않는다.
4. 거절하면 매초 반복 요청하지 않는다. ‘위치 권한 허용하고 공유 시작’으로 재시도한다. 다시 묻지 않음 상태면 앱 설정을 연다.
5. 앱 재실행으로 복구한 픽업은 기존 ‘이전 픽업 계속하기’ 확인을 유지한다. 픽업 종료 뒤에는 공유하지 않는다.

위치 권한은 앱이 대신 허용할 수 없다. POST_NOTIFICATIONS 허용 여부는 위치 공유 시작을 가로막지 않는다. ‘위치 권한 필요해요’, ‘공유 연결 중’, 실제 예상 시간을 구분해 표시한다.

## 확인

- 첫 요청 → 허용 후 자동 시작, 거절 뒤 반복 요청 방지, 설정 허용 후 재개 정책 시험 3개 통과.
- 앱이 배경에 있거나 주행 중·상태 미확인·복구 확인 전·픽업 종료 상태에서는 요청/시작하지 않는 정책 시험 포함.
- 단위 시험·lint·debug 및 시험 APK 빌드 통과. 실제 차량에서의 최초 권한 창·시동 재시작 시험과 구분한다.
