# 준비 상태 수신 확인

차량은 픽업 상태를 조회하고 적용한 뒤, 탑승자 ID와 준비 순번을 서버에 보낸다. 화면에서 운전자가 읽었는지는 확인하지 않는다. 화면 밖 공유 서비스가 받은 경우도 앱 수신에 포함한다.

같은 순번을 이미 확인했으면 쓰기 요청을 반복하지 않는다. 실패한 확인은 다음 정상 조회 뒤 재전송한다. 네트워크 응답을 기다리느라 준비 상태 표시를 늦추지는 않는다. 픽업·탑승자가 바뀌면 이전 응답을 새 상태에 적용하지 않는다. 기존 서버가 새 응답 필드를 보내지 않으면 확인 API를 호출하지 않는다.

## 확인

- JVM 42건 통과, debug·androidTest APK 빌드와 lint 통과.
- Pleos 에뮬레이터의 실제 컨트롤러·HTTP 클라이언트 시험 통과: 수신 확인 실패 후 재조회·재전송, 확인한 순번의 중복 전송 방지, 다음 준비 상태 수신.
- 이 시험은 HTTP 대역 서버다. 실차·실제 운전자 열람 시험이 아니다.

서버·웹 배포만으로 설치된 차량 앱이 바뀌지는 않는다. 새 APK를 설치해야 웹에서 차량 전달 완료를 확인할 수 있다.
