# 차량 화면 조작 개선

2026년 11월 5일, 0.2.23-preview에 반영한 내용이다.

- 픽업 시작과 초대 등 주요 행동을 크게 유지하고, 새로고침·연결 관리·취소는 보조 버튼으로 구분했다.
- 받은 요청은 수락 대기·다음 픽업·진행 중으로 구분하고, 누르면 할 수 있는 행동을 함께 표시한다.
- 탑승자 이름과 메시지를 분리했다. 메시지는 별도 영역에서 줄바꿈해 보여준다.
- 설정 화면과 선택 목록에서 휠 입력마다 고정 거리를 다시 계산하던 처리를 제거하고 Android 기본 스크롤을 사용한다.

## 확인 범위

단위 시험, Android Lint, debug 앱·시험 APK 빌드를 통과했다. 서명한 release APK를 별도로 게시한다. 트랙패드 관성의 실제 체감과 실차 조작은 자동 검사만으로 통과했다고 기록하지 않는다. 내비 SDK·요청 수락·주행 중 조작 제한은 기존 처리를 유지한다.
