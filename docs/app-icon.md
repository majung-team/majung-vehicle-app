# 차량 앱 아이콘

웹과 같은 마중 심볼을 사용한다. 두 갈래가 한 지점에서 만나는 형태이며 기존 M 글자를 교체했다.
벡터 리소스라 화면 밀도에 맞춰 그린다.

![차량 앱 아이콘](media/vehicle-app-icon-2026-10-28.png)

APK에 포함된 애플리케이션 아이콘을 독립 Pleos 에뮬레이터에서 불러와 표시를 확인했다.
현재 게시 버전은 0.2.11-preview / versionCode 13이다. 기존과 같은 서명을 유지한다.

일반 사용은 ‘마중’ 앱 하나로 진행한다. SDK 진단용 `probe` 모듈은 개발 코드로 남기지만
사용자 에뮬레이터에서는 ‘마중 SDK 확인’ 앱과 해당 시험 앱을 제거했다.
기존 마중 앱·등록·진행 중 픽업 데이터는 삭제하지 않았다.
