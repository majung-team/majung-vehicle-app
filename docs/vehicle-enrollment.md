
# 차량 최초 연결 및 QR 등록

마중 차량 앱을 처음 사용할 때 운전자 계정과 차량을 연결하는 과정을 정리한 문서다.

차량에서 QR코드를 생성하고, 운전자 본인의 휴대전화에서 카카오 로그인 후 연결을 요청한다. 차량에서 계정을 확인하고 승인하면 등록이 완료된다.

관리자 코드를 별도로 발급받거나 입력할 필요는 없다.

> 이 기능은 마중 서비스 내 차량과 운전자 계정을 연결하는 절차다. 실제 차량 소유권이나 차대번호(VIN)를 인증하는 기능은 아니다.

---

## 1. 최초 연결 흐름

### 차량에서 QR 생성

1. 차량 앱 실행
2. 위치 공유 안내 확인 및 동의
3. **휴대전화로 시작하기 · QR 만들기** 선택
4. 차량 화면에 QR코드 표시

### 운전자 휴대전화

1. 차량 QR코드 스캔
2. 마중 웹 접속
3. 카카오 로그인
4. 닉네임 설정
5. **이 계정으로 차량 연결 요청** 선택

### 차량에서 최종 승인

1. 휴대전화의 연결 요청 수신
2. 차량에 표시된 닉네임과 마중 ID 확인
3. 본인 계정이 맞는지 확인
4. **이 계정으로 연결** 선택
5. 차량 등록 및 운전자 계정 연결 완료

휴대전화에서 연결을 요청한 것만으로 등록이 완료되지는 않는다.

차량에서 최종 승인해야 실제 차량 권한이 저장된다.

---

## 2. QR코드 및 요청 관리

### 유효 시간

QR코드는 생성 후 **5분간 유효**하다.

만료된 QR코드는 다시 사용할 수 없으며, 차량에서 새로운 QR코드를 생성해야 한다.

### 새 QR 생성

새로운 QR코드를 생성할 때는 이전 연결 요청을 먼저 취소한다.

기존 QR과 새로운 QR이 동시에 유효한 연결 요청으로 처리되지 않도록 관리한다.

### 연결 요청 수신

휴대전화에서 연결을 요청하면 QR 화면을 닫고 계정 확인 화면을 표시한다.

이때 차량에는 요청한 계정의 닉네임과 마중 ID가 나타난다.

잘못된 계정이 요청했다면 승인하지 않고 새 QR코드를 생성한다.

---

## 3. 연결 권한과 보안

차량 최초 연결 과정에서는 임시 연결 권한과 정상 차량 권한을 구분한다.

### 임시 연결 권한

최초 등록이 완료되기 전에는 연결 대기용 권한을 사용한다.

해당 권한은 기존 차량 접근 권한과 분리하여 저장한다.

- 별도의 암호화 저장 파일 사용
- 별도의 Android Keystore 키 사용
- QR코드에 임시 연결 권한을 직접 포함하지 않음
- 차량 최종 승인 전 정상 차량 권한으로 사용하지 않음

### 정상 차량 권한

차량에서 운전자 계정을 확인하고 승인하면 정상 차량 권한을 저장한다.

이후 임시 연결 대기 기록은 삭제한다.

```text
차량 QR 생성
      ↓
임시 연결 권한 저장
      ↓
운전자 휴대전화 로그인
      ↓
차량 연결 요청
      ↓
차량에서 계정 확인 및 승인
      ↓
정상 차량 권한 저장
      ↓
임시 연결 기록 삭제
      ↓
최초 연결 완료
```

임시 권한과 정상 권한을 분리하여 연결이 완료되지 않은 상태에서 차량 기능에 접근하는 것을 제한한다.

---

## 4. 연결 중단 및 복구

최초 연결 도중 네트워크가 끊기거나 앱이 다시 실행되는 상황을 고려한다.

### 승인 응답이 끊긴 경우

차량에서 연결 승인을 요청한 후 응답을 받지 못했다면, 같은 승인 요청을 자동으로 반복하지 않는다.

대신 서버의 현재 연결 상태를 조회한다.

1. 연결 승인 요청
2. 네트워크 오류 또는 응답 중단
3. 서버에 현재 등록 상태 조회
4. 등록 완료 여부 확인
5. 완료 상태라면 정상 차량 권한 복구
6. 미완료 상태라면 연결 대기 상태 유지

서버가 이미 승인한 요청을 다시 승인하여 중복 처리하는 상황을 방지하기 위한 흐름이다.

### 암호화 저장 실패

서버의 연결 승인이 완료됐더라도 정상 차량 권한을 로컬에 저장하지 못할 수 있다.

이 경우 임시 연결 권한을 즉시 삭제하지 않는다.

기존 대기 권한을 유지하고 서버 상태를 다시 확인하여 복구할 수 있도록 구성했다.

정상 차량 권한 저장이 확인된 뒤 대기 기록을 정리한다.

### 앱 재실행

연결 도중 앱을 종료했다가 다시 실행하면 저장된 임시 연결 정보를 확인한다.

유효한 연결 대기 상태가 있다면 서버 조회를 통해 현재 상태를 복구한다.

통신 실패만으로 연결 요청이나 승인을 자동 재전송하지 않는다.

## 5. 미등록 상태의 차량 화면

차량이 아직 등록되지 않은 상태에서도 주요 메뉴 사이를 이동할 수 있다.

| 메뉴 | 미등록 상태 동작 |
| --- | --- |
| **픽업** | 최초 연결 안내 및 연결 버튼 표시 |
| **받은 요청** | 등록 상태에 맞는 안내 표시 |
| **설정** | 차량 최초 연결 기능 제공 |

미등록 상태에서는 실제 픽업 생성을 제한한다.

픽업 화면을 선택했다고 설정 화면으로 자동 이동시키지 않고, 현재 화면에서 연결 안내를 제공한다.

사용자는 필요한 시점에 설정 화면으로 이동하거나 연결 절차를 시작할 수 있다.

## 6. 검증 결과

별도의 Pleos 시험 장치에서 다음 항목을 확인했다.

| 검증 항목 | 결과 |
| --- | --- |
| 미등록 상태에서 설정 → 픽업 화면 이동 | 확인 |
| 픽업 화면 유지 및 최초 연결 버튼 표시 | 확인 |
| 승인 응답 중단 후 GET 요청으로 상태 복구 | 확인 |
| 복구 과정에서 승인 요청 중복 전송 방지 | 확인 |
| 정상 차량 권한 암호화 저장 실패 처리 | 확인 |
| 저장 실패 후 임시 권한 유지 | 확인 |
| 서버 상태 재확인을 통한 연결 복구 | 확인 |

위 검증은 별도 Pleos 시험 환경에서 수행한 결과다.

실제 휴대전화에서 QR코드를 스캔하고 카카오 로그인부터 차량 승인까지 진행하는 전체 연결 흐름은 별도 사용자 시험이 필요하다.

## 7. 이용 시 주의사항

### 운전자와 탑승자 연결 구분

차량 최초 등록은 운전자 본인의 계정을 연결하는 과정이다.

탑승자는 차량 최초 등록을 진행하지 않는다.

탑승자와 연결하려면 차량의 **사람 찾기 · 연결 관리** 또는 픽업 초대 기능을 사용한다.

### 배포 버전 확인

최초 연결 기능을 정상적으로 이용하려면 관련 서버·웹 기능이 반영된 버전이 필요하다.

서버와 웹의 배포 상태를 확인한 뒤 해당 버전에 맞는 차량 APK로 시험한다.

기존 APK를 사용하는 경우 새로운 연결 기능이 표시되지 않을 수 있다.

### 위치 공유

차량 등록이나 운전자 계정 연결만으로 탑승자에게 차량 위치가 공개되지는 않는다.

위치 정보는 유효한 픽업이 시작되고 해당 탑승자에게 접근 권한이 있는 경우 제공한다.
