# 차량 첫 연결 QR

차량에서 ‘휴대전화로 시작하기’를 누르면 운전자 본인 휴대전화로 스캔할 QR이 나온다. 카카오 로그인·닉네임 설정 후 연결을 요청하고, 차량에 표시된 닉네임·마중 ID를 확인해 연결한다. 관리자 코드를 받거나 입력하지 않는다. 차량 소유권 인증은 아니다.

처음 연결 대기 권한은 기존 차량 권한과 다른 파일·Keystore 키로 암호화 저장한다. QR에는 이 권한을 넣지 않는다. 차량 확인이 끝나야 정상 차량 권한으로 저장하고 대기 기록을 지운다. 앱을 다시 열거나 완료 응답이 끊겼다면 상태 조회로 복구한다. 통신 실패 때 연결 요청·승인을 자동 재전송하지 않는다.

QR은 5분 동안만 유효하다. 새 QR을 만들면 이전 요청을 먼저 취소한다. 휴대전화가 요청하면 QR 창을 닫고 확인 버튼을 표시한다. 잘못된 계정이면 승인하지 말고 새 QR을 만든다.

차량 미등록 상태에서도 픽업·요청·설정 탭을 이동할 수 있다. 픽업 탭은 첫 연결 안내를 보여주고, 등록 전 픽업 생성은 막는다. 기존처럼 픽업 탭을 눌렀다가 설정으로 되돌리지 않는다.

별도 Pleos 시험 장치에서 확인한 항목:
- 미등록 상태에서 설정 → 픽업 탭 이동 유지와 연결 버튼 표시
- 차량 확인 응답이 끊긴 뒤 GET으로 복구, 중복 승인 요청 없음
- 차량 권한의 암호화 저장 실패 뒤 대기 권한 유지·재확인 복구

실제 휴대전화 QR 스캔·카카오 로그인은 사용자 시험으로 별도 확인한다. 서버·웹 새 버전이 먼저 배포돼야 한다.
