
# 현재 개발 및 유지보수 기준

**기준일: 2026년 10월 28일**

마중은 초기 공동 개발 단계 이후 현재 1인 유지보수 체제로 후속 개발·검증·배포를 진행하고 있다.

초기 역할 분담과 실제 작성 코드는 기존 Git 커밋 및 Pull Request 이력으로 보존한다. 담당 체계 변경이 이전 기여자의 작업을 대체하거나 삭제하는 것은 아니다.

이 문서는 현재 개발 기준을 안내하며, 초기 기능 계획이나 역할 분담표를 새로 작성하기 위한 문서는 아니다.

## 1. 개발 및 유지보수

| 항목 | 기준 |
| --- | --- |
| 초기 개발 | 공동 개발 및 역할 분담 |
| 현재 후속 개발 | 1인 유지보수 |
| 코드 작성 이력 | 실제 커밋 작성자 기준 |
| 기능별 검증 | 실행 환경과 테스트 결과 기준 |
| 배포 이력 | 실제 배포 버전 및 커밋 기준 |
| 남은 작업 | 최신 이슈 및 개발 현황에서 관리 |

기능별 기여를 확인할 때는 PR 생성자만으로 작성자를 판단하지 않고 실제 변경 커밋과 파일 이력을 함께 확인한다.

## 2. 현재 서비스 기준

마중은 차량 앱, 백엔드, 모바일 웹으로 구성된다.

일반적인 최초 연결은 다음 순서로 진행한다.

1. 차량에서 최초 연결 QR 생성
2. 운전자 본인의 휴대전화로 QR 열기
3. 카카오 로그인 및 닉네임 설정
4. 차량에서 계정 확인 및 연결 승인
5. 내비게이션 경로 확인 후 픽업 이용

관리자 일회용 등록 코드는 내부 시험·관리 절차와 구분한다.

차량 등록 권한과 픽업 접근 권한도 별도로 관리한다.

마중의 계정 연결은 서비스 이용 권한을 설정하기 위한 절차이며, 실제 차량의 VIN 또는 소유권 인증을 의미하지 않는다.

## 3. 구현 및 검증 상태 구분

개발 현황을 기록할 때 다음 단계를 구분한다.

| 구분 | 의미 |
| --- | --- |
| 구현 | 해당 기능의 코드 작성 |
| `main` 반영 | 관련 변경 사항의 기준 브랜치 병합 |
| 운영 배포 | 서버·웹 또는 차량 APK에 해당 변경 반영 |
| 자동화 테스트 | 단위·통합·계측 테스트에서 확인 |
| 공식 에뮬레이터 | Pleos 환경에서 실제 동작 확인 |
| 실제 휴대전화 | 실기기를 이용한 기능 확인 |
| 실차 검증 | 실제 차량에서 동작 확인 |

코드가 구현됐거나 `main`에 반영됐다는 사실만으로 운영 배포 및 실기기 검증까지 완료됐다고 기록하지 않는다.

또한 에뮬레이터에서 확인한 결과를 실제 차량의 주행·시동·절전 환경에서 검증한 결과로 표현하지 않는다.
