# 픽업 장소 바꾸기

탑승자가 장소를 제안하면 주차 중인 차량 화면에 제안 장소가 나타난다.

1. **제안 장소 확인**을 누른다. 최종 목적지와 다른 경유지는 두고 픽업 경유지를 바꾼다. 추천 경로를 다시 찾는다.
2. 내비에서 새 장소와 경로가 맞는지 확인한다.
3. 새 장소와 ETA가 확인되면 **새 장소 확정**이 켜진다.
4. 확정 후 탑승자 화면의 장소도 바뀐다. 새 경로 확인 전에는 이전 위치·ETA를 보내지 않는다.

변경 도중 앱을 종료했다면 같은 제안 ID로 현재 내비 경로를 다시 읽는다. 알 수 없는 경로를 복구 과정에서 임의로 만들지 않는다. 새 장소를 확인하지 못하면 확정할 수 없다. 제안이 바뀌었다면 새 제안으로 다시 확인한다.

주행 중에는 이 조작을 사용할 수 없다. 준비 완료는 차량 앱 수신 여부와 운전자의 읽음 여부를 구분한다.

## 확인한 범위

2026-10-26 Pleos 에뮬레이터와 로컬 Spring 서버를 함께 사용했다.

- 두 경유지 중 픽업 경유지만 교체
- 최종 목적지와 다른 경유지 유지
- 새 SDK 연결에서 기존 좌표 캐시 없이 장소 다시 확인
- 서버 장소 버전 증가와 새 ETA 전송
- SDK 확인 전 확정 버튼 비활성화

시험은 `PlaceConfirmationSdkTest`, `PlaceProposalScreenTest`에 있다. 실제 휴대전화·실차 시험과는 구분한다. 공개 서버 반영 여부는 배포 기록에서 확인한다.
